# V0.9 — Safari Bookmark Sync / Safari 收藏夹同步

First public preview for Apple Silicon Macs running macOS 13 or later.

- Choose Edge → Safari (default) or Safari → Edge.
- Incremental or mirror sync in either direction.
- Automatic backups before writes, manual backup, verification, restore and deletion to Trash.
- Native menu bar Quick Panel, progress feedback, English and Simplified Chinese.

Download the `.pkg` installer below. Check its SHA-256 against `SHA256SUMS.txt`.
The app is ad-hoc signed; this installer is **not Developer ID signed or notarized**. macOS may block opening it. Safari access must be authorized separately in Full Disk Access. Browser formats and cloud sync may affect compatibility. Back up and verify your first sync.
