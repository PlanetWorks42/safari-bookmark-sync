# Changelog / 更新日志

## 0.9.0 — 2026-10-27 · First public preview / 首个公开预览

- Select Edge → Safari (default) or Safari → Edge.
- Incremental and mirror modes in either direction.
- Complete backups of both browsers, verification, restore, rollback protection, and deletion to Trash.
- Native three-pane UI, menu bar Quick Panel, Dock fallback, and off-screen/notch diagnostics.
- English / Simplified Chinese, system-language mode, and localized installer pages.
- Added recovery guidance for menu bar managers that hide the status icon.
- MIT-licensed source and bilingual documentation.

双向可选、默认 Edge → Safari；两种模式；双边备份及恢复保护；原生三面板、快捷面板和菜单栏位置检测；中英文及双语安装器。提供第三方菜单栏工具隐藏图标时的恢复指引。采用 MIT 许可证，提供双语文档。
