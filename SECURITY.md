# Security and data handling / 安全与数据

Bookmark files contain personal URLs and sometimes sensitive tokens. Do not share real bookmark files, backup folders, or full logs in public issues. Reproduce problems with synthetic data whenever possible.

This app reads and writes local browser data after user authorization. Full Disk Access is managed by macOS, not granted by the installer. Closing a window does not revoke permission or quit the app; use Quit to stop scheduling.

If a vulnerability is discovered after the repository is published, use GitHub private vulnerability reporting when available, or contact the maintainer privately before disclosing sensitive details. Do not include credentials or private browsing data in an initial public report.

书签可能包含私人网址或令牌。公开反馈不要附上真实书签、备份或完整日志。请尽量使用模拟数据。完全磁盘访问由 macOS 管理，安装器不会代为授权。关闭窗口不等于退出软件；请用“退出”停止定时任务。漏洞详情及敏感复现数据应先私下联系维护者。
